# I/O Redirections and filters

- 0-hello_world: Prints Hello, World followed by a new line.
- 1-confused_smiley: Displays a confused smiley.
- 2-hellofile: Displays the contents of /etc/passwd.
- 3-twofiles: Displays the contents of /etc/passwd and /etc/hosts.
- 4-lastlines: Displays the last 10 lines of /etc/passwd.
- 5-firstlines: Displays the first 10 lines of /etc/passwd.
- 6-third_line: Displays the third line of the iacta file.
- 7-file: Creates a file with a special name containing Best School.
- 8-cwd_state: Saves the output of ls -la to ls_cwd_content.
- 9-duplicate_last_line: Duplicates the last line of iacta.
- 9-duplicate_last_line: Duplicates the last line of iacta.
- 10-no_more_js: Deletes all regular .js files in the current directory and subdirectories.
- 11-directories: Counts directories and subdirectories, including hidden ones.
- 12-newest_files: Displays the 10 newest files.
- 13-unique: Displays words that appear exactly once, sorted.
- 14-findthatword: Displays lines containing root from /etc/passwd.
- 15-countthatword: Counts lines containing bin in /etc/passwd.
- 16-whatsnext: Displays root lines and the three following lines.
- 17-hidethisword: Displays lines that do not contain bin.
- 18-letteronly: Displays lines starting with a letter.
- 19-AZ: Replaces A with Z and c with e.
- 20-hiago: Removes all c and C characters from input.
- 21-reverse: Reverses input text.
- 22-users_and_homes: Displays users and their home directories, sorted by username.
- 23-empty_casks: Finds empty files and directories, including hidden ones, and displays names only.
